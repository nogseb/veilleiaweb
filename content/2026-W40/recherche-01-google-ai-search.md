# Google AI Search — veille du 22 au 28 septembre 2026

## Retenues

### 1. Google Search Central — reporting Search Console pour la recherche multimodale

- **Titre :** *Announcing web multimodal Search performance reporting in Search Console*
- **Éditeur :** Google Search Central Blog
- **Date publiée :** jeudi 24 septembre 2026
- **URL :** https://developers.google.com/search/blog/2026/09/web-multimodal-in-sc?hl=en
- **Type :** annonce institutionnelle / source primaire
- **Vérification :** URL accessible et page affichant explicitement la date du 24 septembre 2026.

Google annonce un reporting Search Console pour la recherche web multimodale, à la fois dans le rapport de performance des résultats Search et dans le « report for Generative AI features ». L’annonce précise que les données concernent les recherches avec Lens, Circle to Search sur Android, les téléversements d’images vers Google Search et la fonction Chrome « Search this image ». Un nouveau filtre de type de recherche « multimodal » est disponible dans les rapports de performance ; les données peuvent être exportées. Le déploiement mondial commence le 24 septembre 2026 et les métriques apparaissent si le site reçoit du trafic provenant de ces requêtes. [1]

## Faits vérifiés

- Libellé publié : « Search Console reporting for web multimodal search ». Il est présenté dans le rapport de performance des résultats Search et dans le « report for Generative AI features ». [1]
- Libellé publié : « The data reported here includes searches with Lens, Circle to Search on Android, image uploads to Google Search, and the Chrome right-click "Search this image" feature. » [1]
- Libellé publié : « To view these insights, use the new multimodal search type filter in the performance reports. » L’annonce indique également : « Click “Export” to download the data and analyze it in your other tools. » [1]
- Libellé publié : « The integration of multimodal search data is rolling out globally starting today. » La page ajoute : « You will start seeing these metrics in your Performance report if your site is receiving traffic from these queries. » [1]
- Aucun chiffre de volume, de taux, de portée ou de performance n’est publié dans cette annonce. Aucun calcul ni transposition n’est donc effectué.

## Angle TBS Education

Le sujet exploitable pour TBS Education est la **mesure de la visibilité dans les nouveaux parcours de recherche**, plutôt qu’une promesse de hausse de trafic. L’annonce montre que Google ajoute une lecture multimodale dans Search Console et l’articule au rapport des fonctionnalités d’IA générative. Pour une école, cela ouvre un suivi éditorial des contenus visuels et des pages susceptibles d’être découvertes via Lens, Circle to Search, l’envoi d’images ou « Search this image ». La recommandation doit rester prudente : Google ne publie ici aucun KPI de performance ni garantie de visibilité ; il faut exploiter les filtres et exports disponibles sur les propriétés concernées.

**Bonus (hors des huit domaines) :** la recherche multimodale élargit le terrain de veille au-delà des requêtes textuelles classiques, mais l’annonce ne fournit pas de comparaison chiffrée entre formats.
